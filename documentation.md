# Документація: зіставлення компаній між двома датасетами

## 1. Підхід до зіставлення

Зіставлення виконується в SQLite через чистий SQL-пайплайн:

1. CSV-файли завантажуються в SQLite (`dataset_1`, `dataset_2`)
2. Очищення даних виконується у 3 послідовних кроки для кожного датасету (`ds1_step1` → `ds1_step2` → `ds1_step3`, аналогічно для DS2)
3. Зіставлення виконується через `LEFT JOIN` за нормалізованою назвою компанії (`ds1.name_clean = ds2.name_clean`), що зберігає всі записи з DS1 і підставляє збіги з DS2
4. Збіги за локацією (країна, штат/провінція, місто, індекс) розраховуються як додаткові прапорці (`match_country`, `match_state`, `match_city`, `match_zip`), але не впливають на матчинг — компанії зіставляються навіть якщо їхні адреси не збігаються
5. Дублікати усуваються через `ROW_NUMBER()` з `PARTITION BY custnmbr_ds1, name_clean_ds1` — для кожної компанії DS1 зберігається лише один збіг

## 2. Виявлені проблеми з якістю даних

- **Назви компаній**: різний регістр, наявність спецсимволів (`"`, `'`, `*`, `#`, `+`, `-`, `.`, `,`, `_`, `%`), суфікси юридичних форм (INC, LTD, LLC, CORP, CO, COMPANY, LIMITED, CORPORATION, LP), префікси C/O
- **Французькі діакритичні символи**: `É`, `È`, `Ê`, `Ë`, `À`, `Â`, `Ô`, `Î`, `Ù`, `Û`, `Ç`, `Ï` зустрічаються в назвах, містах та штатах
- **Штати/провінції**: змішані формати — повні назви (ONTARIO, QUEBEC, BRITISH COLUMBIA), скорочення (ON, QC, BC), назви міст замість провінцій (TORONTO, MONTREAL, KRONAU)
- **Країни**: різні позначення (CANADA / CA / CAN, USA / US / UNITED STATES / UNITED STATES OF AMERICA), сміттєві значення (CONTRACT...)
- **Міста**: префікси ST/STE замість SAINT/SAINTE, пунктуація (коми, крапки, лапки)
- **Поштові індекси**: пробіли та дефіси всередині кодів (канадські коди виду "K1A 0B1" vs "K1A0B1")

## 3. Нормалізація та перетворення

Очищення виконується у 3 кроки для кожного датасету:

### Крок 1 — базове очищення (`01_ds1_step1.sql`, `01_ds2_step1.sql`)
- **Назва**: `UPPER` + `TRIM` + `COALESCE`, видалення спецсимволів (`"`, `'`, `*`, `#`, `%`, `_`), заміна (`+`, `-`, `,`, `.`) на пробіли
- **Місто**: `UPPER` + `TRIM` + `COALESCE`, видалення ком, крапок, лапок
- **Штат**: `UPPER` + `TRIM` + `COALESCE`
- **Країна**: `UPPER` + `TRIM` + `COALESCE`
- **Індекс**: `UPPER` + `TRIM` + `COALESCE`, видалення пробілів та дефісів

### Крок 2 — заміна діакритичних символів (`02_ds1_step2.sql`, `02_ds2_step2.sql`)
- Заміна французьких літер на ASCII-еквіваленти у полях: назва, місто, штат
- `É/È/Ê/Ë` → `E`, `À/Â` → `A`, `Ô` → `O`, `Î/Ï` → `I`, `Ù/Û` → `U`, `Ç` → `C`

### Крок 3 — семантична нормалізація (`03_ds1_step3.sql`, `03_ds2_step3.sql`)
- **Назва**: видалення частини після `C/O`, видалення суфіксів юридичних форм (INC, LTD, LIMITED, LP, LLC, CORPORATION, CORP, CO, COMPANY), згортання множинних пробілів
- **Місто**: уніфікація `ST` → `SAINT`, `STE` → `SAINTE`, згортання множинних пробілів
- **Штат**: приведення до 2-літерних кодів провінцій/штатів (повні назви та міста-столиці → коди)
- **Країна**: приведення до 2-літерних кодів (`CANADA`/`CAN` → `CA`, `USA`/`UNITED STATES` → `US`), очищення сміттєвих значень

### Аналітика (`sql/analytics/task1.sql`)
- `LEFT JOIN` DS1 з DS2 за `name_clean`
- Розрахунок прапорців збігу за країною, штатом, містом, індексом
- Дедуплікація через `ROW_NUMBER()` (один збіг на компанію DS1)

## 4. Розраховані метрики

У результуючій таблиці `task1` для кожної пари є прапорці збігу за локацією:

| Прапорець | Опис |
|---|---|
| `match_country` | 1, якщо країна збігається |
| `match_state` | 1, якщо штат/провінція збігається |
| `match_city` | 1, якщо місто збігається |
| `match_zip` | 1, якщо поштовий індекс збігається |

Наявність/відсутність збігу визначається за полем `custnmbr_ds2`: якщо воно `NULL` — збігу не знайдено.

## 5. Структура проєкту

```
main.py                        — основний скрипт (завантаження CSV → виконання SQL → експорт CSV)
data/
  input/
    company_dataset_1.csv      — вихідний датасет 1
    company_dataset_2.csv      — вихідний датасет 2
  output/
    task1.csv                  — результат зіставлення
sql/
  clean/
    01_ds1_step1.sql           — крок 1: базове очищення DS1
    01_ds2_step1.sql           — крок 1: базове очищення DS2
    02_ds1_step2.sql           — крок 2: заміна діакритичних символів DS1
    02_ds2_step2.sql           — крок 2: заміна діакритичних символів DS2
    03_ds1_step3.sql           — крок 3: семантична нормалізація DS1
    03_ds2_step3.sql           — крок 3: семантична нормалізація DS2
  analytics/
    task1.sql                  — зіставлення (LEFT JOIN) + прапорці збігу
data.db                        — SQLite база даних (створюється автоматично)
```
